# QuickNotes System Design Project

## Description
A full-stack prototype client and comprehensive systems architecture blueprint for QuickNotes, designed to support up to 1 million users.

## How to Run
1. Open `index.html` in any web browser or live server preview in Spck Editor.
2. Click **Load Notes** to fetch mock data via `api.js`.
3. Use the form to publish new notes or delete existing ones.
